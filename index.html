CEP4HFP: Complex Event Processing for Heart Failure Prediction

Afef Mdhaffar, Ismael Bouassida Rodriguez, Khalil Charfi, Leila Abid, and Bernd Freisleben
View Publication

Topic: Real-time biomedical stream processing and predictive medical alerts. Role: Lead Developer & Co-author. Engineered the core real-time telemetry processing pipeline. Journal: IEEE Transactions on Nanobioscience (2017). Why It Matters: This peer-reviewed research addresses early heart failure detection by processing high-frequency wearable ECG streams. We implemented a hybrid complex event processing (CEP) and statistical reconciliation engine that computes patient-specific cardiac thresholds dynamically on the fly. In clinical testing with a 50-patient cohort, the system detected life-threatening cardiovascular abnormalities in under 2 seconds with a 94% sensitivity score, demonstrating how low-latency edge analysis can safely run on resource-constrained medical hardware without false-alert fatigue.
